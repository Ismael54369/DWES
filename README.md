# 📚 DWES - Desarrollo Web en Entorno Servidor

¡Bienvenido/a al repositorio del módulo de **Desarrollo Web en Entorno Servidor (DWES)**!

Este espacio está dedicado a almacenar todas las prácticas, ejercicios y proyectos realizados durante el curso. El objetivo principal de este módulo es aprender a desarrollar aplicaciones web dinámicas que se ejecutan en el lado del servidor, interactuando con bases de datos y generando contenido de forma dinámica.

## 🛠️ Puesta en Marcha

Para ejecutar los proyectos y ejercicios de este repositorio en tu entorno local, necesitarás un stack de desarrollo como XAMPP, WAMP o MAMP.

1.  **Clona el repositorio** en la carpeta `htdocs` (para XAMPP) o `www` (para WAMP/MAMP) de tu servidor local:
    ```bash
    git clone https://github.com/Ismael543692/DWES
    ```

2.  **Inicia los servicios** de Apache y MySQL desde el panel de control de tu stack.

3.  **Accede a los proyectos** a través de tu navegador web, normalmente en una URL como `http://localhost/DWES/`.
